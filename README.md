Board Specifications:
 - 4 layers (Signal, GND, 3v3, Signal)
 - STM32L051 MCu
 - CC2500 rf transceiver
 - PCB antenna (see TI documentation SWRA118, DN035 for more info on PCB antennas)

Please note that this board is untested as of yet.
